# Sources

The guidelines in this skill are our own summaries and adaptations. For depth, read the originals:

- Robert C. Martin, *Clean Architecture* (2017): the dependency rule, boundaries, SOLID at component level.
- Robert C. Martin, *Clean Code* (2008): naming, small functions, error handling.
- Alistair Cockburn, "Hexagonal Architecture" (ports and adapters), 2005.
- Martin Fowler, *Refactoring* (2nd ed., 2018): behaviour-preserving changes in small steps.
- Martin Fowler, *Patterns of Enterprise Application Architecture* (2002).
- Eric Evans, *Domain-Driven Design* (2003); Vaughn Vernon, *Implementing Domain-Driven Design* (2013).
- Jimmy Bogard, "Vertical Slice Architecture" (2018).
- Kent Beck, *Test-Driven Development: By Example* (2002); Vladimir Khorikov, *Unit Testing: Principles, Practices,
  and Patterns* (2020).
- Microsoft, ".NET application architecture guides" and the ASP.NET Core / Blazor documentation (Microsoft Learn).
- Microsoft, Framework Design Guidelines (Cwalina, Abrams), for public API naming.
